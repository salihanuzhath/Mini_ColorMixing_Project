# 🎨 ColourMix – Guess & Create

## 📌 Project Description
ColourMix is an interactive colour-mixing game designed for children. It helps children learn about primary and secondary colours through fun activities, animations, and colour-guessing challenges.

Players select a character, choose colours for two hands, mix the colours, and guess the resulting colour from four options.

## 🎯 Objectives
- Teach children basic colour combinations.
- Improve colour recognition and observation skills.
- Make learning fun through interactive gameplay.
- Encourage children to think and guess the correct mixed colour.

## ✨ Features
- Welcome screen and game instructions.
- Boy and girl character selection.
- Interactive colour-painting hands.
- Colour palette to select different colours.
- Colour-mixing animation and countdown.
- Multiple-choice colour guessing.
- Score and level tracking.
- Best-score saving.
- Sound effects and confetti animations.
- Eye Comfort mode.

## 🕹️ How to Play
1. Click the **Play** button.
2. Select a boy or girl character.
3. Choose colours from the palette.
4. Apply colours to both hands.
5. Click the **Mix Colours** button.
6. Watch the countdown and colour-mixing animation.
7. Select the correct mixed colour from four options.
8. Earn points and move to the next level.

## 🛠️ Technologies Used
- **HTML5** – Structure of the game.
- **CSS3** – Styling, layouts, animations and visual effects.
- **JavaScript** – Game logic, colour mixing, scoring and interactions.
- **Local Storage** – Saving the best score and game progress.

## 🚀 How to Run the Project
1. Download or clone the project.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser.
4. Alternatively, use the **Live Server** extension in VS Code.
5. Click Play and enjoy the game!
